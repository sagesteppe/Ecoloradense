Do CV strategies differ in model-to-model consistency?

Permutation test of replicate dispersion across holdout strategies

Author

Reed Benkendorf

Published

October 24, 2026

Question. Eyeballing the refinement grids, the random (classic) holdout looks like its per-model precision scatters more widely than the spatial strategies — i.e. random is the least consistent replicate-to-replicate. Is that spread genuinely larger, or an artifact of random simply having more fits spread across the whole PA-ratio sweep?

Design. “Consistency” is spread at matched conditions. The ratio sweep and resolution move the metric around for real reasons, so we never compare raw pooled spread. Instead:

  1. A cell = one (tree, resolution, PAratio, distOrder) combination. Within a cell the only thing that varies is the seed (the replicate).
  2. Each cell with >= min_reps seeds yields one dispersion value (SD or MAD across seeds).
  3. Those cell-level dispersions, tagged by CV strategy, are the data. A permutation test shuffles the strategy labels across cells to ask whether random’s typical within-cell spread is larger than chance.

This is re-runnable: as LMPO / spatial-mapping / finer-resolution fits land, rerun and the spatial strategies gain scoreable cells. The replication table below shows how thin each strategy currently is.

Build the per-fit table

One row per fitted model, carrying the chosen metric. own reads the model’s own test-split metrics; gt reads the 2026 field ground truth and pools the two interpolation distance bins (<=270m, >270m) by point count. nAP = (PR-AUC − prevalence)/(1 − prevalence), with the own-split prevalence taken from the PA ratio and the GT prevalence from the field subset.

Code 
pa_prev <- function(x) {                         # "1:1.023" -> prevalence 1/(1+1.023)
  r <- suppressWarnings(as.numeric(sub("^1:", "", x))); ifelse(is.na(r), NA, 1 / (1 + r))
}

per_fit <- if (params$source == "own") {
  read.csv(file.path(PROJ, "results_summary/all_fit_metrics.csv"), stringsAsFactors = FALSE) |>
    filter(tree %in% names(cv_lab), resolution == RES) |>
    mutate(prevalence = pa_prev(PAratio),
           nAP = (pr_auc - prevalence) / (1 - prevalence)) |>
    select(fname, tree, resolution, PAratio, distOrder, seed,
           pr_auc, roc_auc, cox_slope, cox_intercept, nAP)
} else {
  read.csv(file.path(PROJ, "results_summary/all_fit_2026gt.csv"), stringsAsFactors = FALSE) |>
    filter(tree %in% names(cv_lab), resolution == RES, grepl("^Interp", domain)) |>
    group_by(fname, tree, resolution, PAratio, distOrder, seed) |>   # pool the 2 interp bins
    summarise(pr_auc        = weighted.mean(pr_auc, n),
              roc_auc       = weighted.mean(roc_auc, n),
              cox_slope     = weighted.mean(cox_slope, n),
              cox_intercept = weighted.mean(cox_intercept, n),
              prevalence    = weighted.mean(prevalence, n), .groups = "drop") |>
    mutate(nAP = (pr_auc - prevalence) / (1 - prevalence))
}

per_fit       <- per_fit[!is.na(per_fit$value), ]

            params$source, params$metric, RES, nrow(per_fit)))

Permutation test — omnibus

Null hypothesis: within-cell dispersion is exchangeable across CV strategies (labels carry no information). Test statistic: the Kruskal–Wallis H on the cell-level dispersions (rank-based, so it does not assume normal dispersions). We shuffle the strategy labels across cells B times and compare.

Code 
grp_ok <- cell_disp |> count(cv) |> filter(n >= 2) |> pull(cv)
cd <- cell_disp |> filter(cv %in% grp_ok) |> mutate(cv = droplevels(cv))

if (nlevels(cd$cv) < 2 || nrow(cd) < 6) {
  cat("Not enough scoreable cells across >=2 strategies yet — rerun once the grid fills.\n")
} else {
  kw_H <- function(y, g) unname(kruskal.test(y, g)$statistic)
  obs  <- kw_H(cd$disp, cd$cv)
  perm <- replicate(params$B, kw_H(cd$disp, sample(cd$cv)))
  p    <- (1 + sum(perm >= obs)) / (params$B + 1)
  cat(sprintf("Omnibus KW H = %.2f over %d strategies, %d cells\n",
              obs, nlevels(cd$cv), nrow(cd)))
  cat(sprintf("Permutation p = %.4g  (parametric KW p = %.4g)\n",
              p, kruskal.test(cd$disp, cd$cv)$p.value))
  hist(perm, breaks = 40, col = "grey85", border = "white",
       main = "Permutation null for KW H", xlab = "H under shuffled labels")
  abline(v = obs, col = "firebrick", lwd = 2);
}

Permutation test — is random the least consistent?

Targeted one-sided contrast: observed statistic = median within-cell dispersion of random minus median of all other strategies pooled. Positive = random more variable. The null shuffles the random / not-random label across cells.

Code 
if (!"classic/random" %in% levels(droplevels(cell_disp$cv)) ||
    sum(cell_disp$cv == "classic/random") < 2 ||
    sum(cell_disp$cv != "classic/random") < 2) {
  cat("Need >=2 scoreable cells for random and >=2 for the rest — not yet.\n")
} else {
  is_rand <- cell_disp$cv == "classic/random"
  stat <- function(flag) median(cell_disp$disp[flag]) - median(cell_disp$disp[!flag])
  obs  <- stat(is_rand)
  perm <- replicate(params$B, stat(sample(is_rand)))
  p_gt <- (1 + sum(perm >= obs)) / (params$B + 1)   # random MORE variable
  cat(sprintf("median disp: random = %.4f, rest = %.4f, difference = %+.4f\n",
              median(cell_disp$disp[is_rand]), median(cell_disp$disp[!is_rand]), obs))
  cat(sprintf("one-sided permutation p (random MORE variable) = %.4g\n", p_gt))

  # pairwise random vs each other strategy
  cat("\nPairwise (random vs each), one-sided permutation p that random is more variable:\n")
  for (g in setdiff(levels(droplevels(cell_disp$cv)), "classic/random")) {
    sub <- cell_disp |> filter(cv %in% c("classic/random", g))
    if (sum(sub$cv == g) < 2) { cat(sprintf("  %-16s (too few cells)\n", g)); next }
    fr  <- sub$cv == "classic/random"
    st  <- function(f) median(sub$disp[f]) - median(sub$disp[!f])
    o   <- st(fr); pp <- (1 + sum(replicate(params$B, st(sample(fr))) >= o)) / (params$B + 1)
    cat(sprintf("  %-16s diff=%+.4f  p=%.4g  (n_random=%d, n_%s=%d)\n",
                g, o, pp, sum(fr), g, sum(!fr)))
  }
}

Secondary: overall pooled spread (descriptive only)

This is what the eye catches in the grids — total spread of each strategy’s models, including the ratio sweep. Fligner–Killeen is a robust test of equal variance, but across the raw values it conflates genuine inconsistency with the sweep, so treat it as a description, not the test.

Caveats

  • Replication gates everything. Until a strategy has several >= min_reps cells, it cannot enter the test. Rerun as fits land; the availability table tracks progress.
  • Own vs GT. source: own tests consistency of each model’s self-assessment; source: gt tests consistency of true field (interpolation) performance. They can disagree — the own-holdout confound ([[cv-comparison-own-holdout-confound]]) means a strategy can be self-consistent yet inconsistent against the field, or vice versa.
  • Cells are the unit. Permuting labels across cells (not individual fits) respects that seeds within a cell are not independent draws.
  • Dispersion choice. sd is the natural “precision” spread; mad is robust to a single wild replicate. If they disagree, a few outlier fits are driving sd — worth reporting both.
  • Metric scale. cox_slope/cox_intercept live on a different scale than pr_auc; compare dispersion only within one metric, never across. ```
